## Project Overview

Performed a comprehensive wireless site survey to evaluate Wi-Fi coverage, signal quality, interference, and access point placement for an optimized wireless network.

## Key Features

- Wi-Fi coverage analysis
- Heatmap generation
- RSSI & SNR analysis
- Channel utilization assessment
- Interference identification
- Wireless optimization recommendations
